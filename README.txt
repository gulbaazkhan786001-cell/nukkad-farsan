Nukkad Farsan website
=====================
index.html  -> the complete website (images are embedded, so this single file works on its own).
images/     -> your original photos, for reuse (Instagram, posters, etc).

How to use:
1. Double-click index.html to open it in a browser.
2. To put it online, upload index.html to any free host (Netlify Drop, GitHub Pages, Cloudflare Pages).

To change prices or WhatsApp numbers, open index.html in a text editor and search for:
  const KH / const BH  (prices)
  916354012611 / 917600127099  (WhatsApp numbers, with 91 country code)
